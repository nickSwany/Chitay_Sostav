# Читай состав

Android-приложение для проверки состава продуктов. Наводишь камеру на штрихкод и сразу видишь оценку продукта, пищевые добавки и уровень их риска.

## Возможности

- **Сканирование штрихкода** через камеру (CameraX + ML Kit Barcode Scanning).
- **Оценка продукта от 0 до 100** и буква Nutri-Score (A–E). Расчёт учитывает калорийность, сахар, насыщенные жиры, соль, белок и клетчатку, а также штрафует за опасные добавки.
- **Расшифровка E-добавок.** Встроенный справочник на 175 добавок с описанием и уровнем риска: безопасна, с осторожностью, опасна. Добавки находятся в составе и по коду, и по названию.
- **Проверка достоверности.** Если в составе есть сахар или соль, а в пищевой ценности стоит 0, приложение предупреждает, что данные могут быть неточными.
- **Добавление и редактирование продуктов.** Если продукта нет в базе, его можно добавить самому, а состав распознать с упаковки камерой (ML Kit Text Recognition).
- **История сканирований**, которая хранится локально на устройстве.
- **Профиль** со статистикой: сколько продуктов отсканировано, добавлено и отредактировано.
- **Поделиться** результатом проверки продукта.

## Стек

| Область | Технологии |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose, Material 3, Navigation Compose |
| Архитектура | Clean Architecture (data / domain / presentation), MVVM |
| DI | Hilt |
| Локальное хранилище | Room |
| Облако | Firebase Firestore, Storage, Analytics, Crashlytics |
| Камера и ML | CameraX, ML Kit Barcode Scanning, ML Kit Text Recognition |
| Изображения | Coil |
| Тесты | JUnit 4, MockK, kotlinx-coroutines-test |

## Структура проекта

```
app/src/main/java/com/example/chitaysostav/
├── data/            # Room, Firestore, справочник добавок, реализации репозиториев
├── domain/          # Модели, интерфейсы репозиториев, use cases
├── di/              # Hilt-модули
└── presentation/    # Экраны Compose и ViewModel
    ├── home/        # Главный экран
    ├── scan/        # Сканер штрихкода
    ├── product/     # Карточка продукта и оценка
    ├── edit/        # Добавление/редактирование, OCR состава
    ├── history/     # История сканирований
    ├── profile/     # Профиль, статистика, политика конфиденциальности
    └── navigation/  # Навигация
```

Продукт сначала ищется в локальной базе Room, затем в Firestore (коллекция `products`, документ называется по штрихкоду). Добавленные пользователем продукты сохраняются в оба места.

## Требования

- Android Studio с поддержкой AGP 9.x
- JDK 11+
- Android 8.0 (API 26) и выше, target SDK 36

## Запуск

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/nickSwany/Chitay_Sostav.git
   ```
2. Создай проект в [Firebase Console](https://console.firebase.google.com/), добавь Android-приложение с package name `com.example.chitaysostav` и включи Firestore.
3. Скачай `google-services.json` и положи его в папку `app/`. Файл не хранится в репозитории.
4. Открой проект в Android Studio, дождись синхронизации Gradle и запусти приложение на устройстве с камерой.
